# Events API

Учебный сервис управления мероприятиями на ASP.NET Core Web API, .NET 10.

## Текущее состояние

Стартовый каркас проекта. CRUD мероприятий, сервис хранения в памяти,
валидация и Swagger будут добавлены на следующих этапах первого спринта.
На этом этапе маршруты ещё не реализованы: ответ 404 ожидаем.

## Запуск

Установите .NET SDK 10. В терминале перейдите в папку с EventsApi.csproj:

```sh
dotnet build
dotnet run
```

Адрес при запуске со стандартным профилем: http://localhost:5095.
Для остановки нажмите Ctrl+C. Swagger пока не подключён.

## Структура

- `Program.cs` — регистрация зависимостей и настройка приложения.
- `Controllers/` — контроллеры API (будут добавлены далее).
- `appsettings.json` — настройки приложения.
- `Properties/launchSettings.json` — локальный профиль запуска.
